# ssh05 0.42.0

Fecha: 25/11/2026

## Nmap embebido

- Se incluye Nmap 7.99 estático para Linux `amd64` y `arm64`, comprimido dentro
  del binario.
- Se extrae a `$XDG_CACHE_HOME/ssh05/nmap/7.99-<plataforma>` con permisos `0700`
  y se verifica por SHA-256 antes de ejecutarlo.
- Se incluyen datos de Nmap: `nmap-services`, `nmap-protocols`,
  `nmap-service-probes`, `nmap-os-db`, `nmap-rpc`, prefijos MAC, scripts NSE y
  `nselib`.
- En otras plataformas se puede usar `--nmap <ruta>`.

## Escaneo de red local

- «Escanear red local» usa descubrimiento `nmap -sn` sobre la red privada
  principal, no un escaneo de puertos de un host.
- Se detectan las interfaces virtuales (Docker, libvirt, túneles) y se evitan.
- Se muestran IP, hostname, MAC, fabricante, tipo de máquina, SO, puertos,
  servicios, versiones, scripts, uptime, distancia y traza.
- La tabla ARP local se usa para completar MAC y fabricante incluso sin root.
- Se puede añadir el host descubierto al inventario de `ssh_config`.

## Opciones de análisis

- Servicios y versiones (`-sV`).
- Scripts NSE (`-sC`) con timeout de 30 s.
- Sistema operativo (`-O --osscan-guess`), requiere root.
- Trazado de ruta (`--traceroute`), requiere root.
- Todos los puertos (`-p-`), con timeout ampliado.
- `sudo -n` opcional para SO/trazado, sin pedir ni guardar contraseña.
- «Ver todo» muestra el informe completo por host.
