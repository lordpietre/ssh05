## Cambios

- **Alias normalizado.** «vuigram server» se guarda como `vuigram-server`; se
  eliminan símbolos no válidos y los errores aparecen dentro del formulario,
  que permanece abierto para corregirlos.
- **Cursor parpadeante** en el campo activo de la búsqueda y de los
  formularios (nuevo/editar host, transferencias, FRP).
- **Menú contextual del host con `→`:** `Conectar`, `Editar`, `Eliminar`.
  - `Editar` abre el mismo formulario con el alias fijo, sin perder la
    contraseña codificada si no se escribe una nueva.
  - `Eliminar` pide confirmación y borra el bloque `Host` de `ssh_config`.
- **`Ctrl+S`** guarda el host sin conectar; `Enter` guarda y conecta.
- **Actualización atómica** de `ssh_config` (`hosts.update`, `hosts.delete`),
  conservando `IdentityFile` y `#!! encPassword` cuando no se cambian.
- **Ayuda revisada**: flechas, menú del host, `/connect`, pegado, contraseña y
  bienvenida.

## Verificación ejecutada

- `make ui-smoke`: 104 comprobaciones, incluidas normalización de alias, menú
  contextual, edición y eliminación.
- Pruebas Go de `hosts.update`/`hosts.delete` (contraseña conservada y rotada).
- Pruebas de alias (`normalizeAlias`) y `bun test`: 58 pruebas.
- `bun run typecheck`, `typecheck:contracts` y tests Go completos.

## Límites conocidos

1. El alias no se puede renombrar desde «Editar»; hay que crear otro host.
2. El cursor mueve solo al final del campo (no hay edición en medio).
