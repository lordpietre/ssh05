## Cambios

- **Identidad ssh05 reunificada.** Cliente `ssh05`, supervisor `ssh05d` y UI
  `prototype/terminal/src/ssh05.ts`. `make trssd` se conserva como alias.
- **Vendor y soporte en el producto.** «Dinámicas Electrónicas» y
  `dinamicas.electronicas@gmail.com` aparecen en `ssh05 -V`, `ssh05d --version`,
  la ayuda del cliente y los metadatos del paquete.
- **Rutas nuevas.** `~/.config/ssh05`, `~/.local/state/ssh05` y
  `$XDG_RUNTIME_DIR/ssh05/control.sock`. Un `~/.config/trss` o
  `~/.local/state/trss` preexistente se adopta una vez por renombrado.
- **Variables nuevas `SSH05_*`.** `TRSS_*` se sigue leyendo como respaldo.
- **Servicio de usuario** `ssh05d.service`; paquete con `ssh05` y `ssh05d`.
- **Compatibilidad heredada intacta:** `~/.tssh.conf`, `TSSH_*` y `~/.tssh/`.

## Artefactos

| Distribución | Arquitectura | Paquete |
|---|---|---|
| Ubuntu | amd64 | `ssh05_0.3.18_ubuntu_amd64.deb` |
| Ubuntu | arm64 | `ssh05_0.3.18_ubuntu_arm64.deb` |
| Debian | amd64 | `ssh05_0.3.18_debian_amd64.deb` |
| Debian | arm64 | `ssh05_0.3.18_debian_arm64.deb` |

Cada `.deb` incluye `usr/bin/ssh05`, `usr/bin/ssh05d` y
`usr/lib/systemd/user/ssh05d.service`. Los `.deb` se generan en CI desde el
tag; el SHA-256 vigente de cada uno se publica en su fichero `.sha256` adjunto:

```sh
sha256sum -c ssh05_0.3.18_ubuntu_amd64.deb.sha256
```

## Instalación

```sh
sudo apt install ./ssh05_0.3.18_ubuntu_amd64.deb
systemctl --user daemon-reload
systemctl --user enable --now ssh05d
```

## Verificación ejecutada

- `CGO_ENABLED=0 go test ./ssh05 ./contracts ./internal/identity ./internal/ipc ./internal/supervisor ./internal/table`:
  correcto; solo falla la línea base conocida `TestTableExample` en terminal
  con color.
- `bun run typecheck`, `bun run typecheck:contracts` y `bun test`: 55 pruebas.
- `make ui-smoke`: 10 pestañas, overflow, recuperación tras caída de la UI,
  workspaces, SCP/SFTP, diagnóstico, política tmux y logins concurrentes.
- `make hostkey-smoke`: conexión con clave correcta y bloqueo al cambiar.
- `make ssh05d-frp-smoke`: TCP, UDP, STCP y XTCP (condicional a STUN) reales.

## Límites conocidos

1. La UI OpenTUI no viaja en el `.deb`; requiere Bun y se ejecuta desde
   `prototype/terminal`.
2. DAT-01 trzsz/Zmodem sigue condicionado a compatibilidad remota; SCP/SFTP
   están operativos.
3. GeoIP de ciudad no incluido; ASN/RDAP y país orientativo sí.
