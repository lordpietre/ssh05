# ssh05 0.42.1

Fecha: 25/11/2026

Revisión de fallos y de opciones sin efecto sobre 0.42.0.

## Opciones sin efecto

- Cerrar sin pestaña activa muestra «No hay pestaña activa».
- Favorito, color y etiquetas sin host muestran un aviso claro.
- FRP sin proxy/endpoint explica que no hay selección.
- Transferencias sin selección explican que no hay transferencia.
- Nmap sin host seleccionado muestra un aviso antes de intentar añadirlo.
- Reconectar una pestaña sin datos muestra un aviso.

## Diálogo de cierre

- Se elimina «Desconectar SSH», que hacía lo mismo que «Cerrar vista».
- Queda «Cerrar conexión y pestaña» y, cuando hay tmux, «Desacoplar tmux».

## Nmap y UI

- El escaneo usa una conexión IPC separada: no bloquea sesiones, hosts ni
  otras operaciones de la UI.
- El escaneo se puede cancelar con `Esc` o con «Cancelar escaneo».
- Al cancelar, el resultado tardío se ignora.
- Sudo sin SO/trazado muestra una advertencia.
- Los saltos de línea de scripts y avisos se normalizan.

## Interacción

- En transferencias, clic en protocolo o recursivo cambia el valor.
- En FRP, clic en el tipo cambia el tipo de proxy.

## Verificación

- Tests Go de Nmap, supervisor y contratos.
- Typecheck y 62 tests de la UI.
- `make ui-smoke` completo.
- Escaneo real con descubrimiento, servicios, SO y trazado.
