# ssh05 0.42.2

Fecha: 25/11/2026

## Bienvenida

- Nueva guía de inicio extensa: qué puedes hacer, sesiones, pestañas,
  workspaces, transferencias, FRP, tmux, diagnóstico y Nmap.
- Resumen de teclado y ratón.
- Cuatro acciones navegables con `←/→`, `Enter` o clic:
  - Empezar
  - Nuevo host
  - Ayuda
  - Salir

- El menú superior ahora se llama «Menú».
- Se elimina el texto del alta de host sobre la contraseña codificada.
- Navegación con flechas izquierda/derecha habilitada en:
  - menú del host;
  - opciones de Nmap (con `Espacio` para cambiar);
  - preferencias;
  - resto de listas y formularios.
- Preferencias incluye `[ Cerrar ]` clicable con ratón.
