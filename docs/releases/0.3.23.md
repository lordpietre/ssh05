## Cambios

- **Overlays opacos.** Menús, preferencias, transferencias, FRP, ayuda,
  diagnóstico y paleta rellenan cada línea hasta el ancho de la terminal, sin
  dejar ver la barra de acciones ni los hosts de fondo.
- Mantiene la navegación completa con flechas introducida en 0.3.22.

## Verificación ejecutada

- `make ui-smoke`: 89 comprobaciones, incluidas las de navegación con flechas.
- `bun run typecheck`, `typecheck:contracts` y `bun test` (55 pruebas).
- UI revisada en tmux: el panel de transferencias ya no muestra texto de fondo.

## Límites conocidos

1. La navegación con flechas no sustituye atajos globales como `Ctrl+K` o
   `Ctrl+T`; ambos siguen disponibles.
2. Los contenedores Docker siguen siendo opt-in en el supervisor.
3. La subida con `trz`/`rz` usa el selector del escritorio.
