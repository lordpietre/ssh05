## Cambios

- **El `.deb` es autosuficiente.** Incluye `ssh05` (cliente), `ssh05d`
  (supervisor), `ssh05-ui` (frontend OpenTUI), el runtime Bun 1.4.5 y las
  dependencias de producción; ya no hay que ejecutar la UI desde el
  repositorio.
- **Supervisor activo por defecto.** El paquete instala
  `/etc/systemd/user/default.target.wants/ssh05d.service`, habilitación global
  de usuario, así que ssh05d arranca al iniciar sesión sin `systemctl`.
- **Arranque bajo demanda.** `ssh05-ui` inicia `ssh05d` si el socket no existe,
  de modo que la primera ejecución tras instalar funciona sin reiniciar sesión
  y sin pasos manuales.
- `Recommends: tmux, zenity` para sesiones persistentes y selectores de
  archivos de trzsz/Zmodem.
- Se añade `THIRD-PARTY.md` con la atribución de Bun y OpenTUI (MIT).

## Verificación ejecutada

- `.deb` extraído y `ssh05-ui` ejecutado desde su árbol instalado: la UI carga
  `Hosts (0)` y se conecta al socket.
- Arranque automático comprobado: con el socket ausente, la UI lanza `ssh05d`
  y espera hasta 5 s; el socket aparece y la UI conecta.
- `make verify`: tests Go, contratos, host key, ui-smoke (10 pestañas,
  recuperación, workspaces, SCP/SFTP, diagnóstico, tmux), FRP real y trzsz.
- `bun run typecheck`, `typecheck:contracts` y `bun test` (55 pruebas).

## Límites conocidos

1. El paquete crece (~56 MB comprimido en amd64) por incluir Bun y la UI.
2. La habilitación global de systemd aplica al siguiente inicio de sesión; la
   UI arranca el supervisor igualmente en la sesión actual.
3. El extremo remoto de trzsz/Zmodem necesita `trz`/`tsz` o `lrzsz` en `PATH`.
4. GeoIP de ciudad no incluido; ASN/RDAP y país orientativo sí.
