# ssh05 0.42.4

Fecha: 25/11/2026

## Transferencias SCP/SFTP

- SFTP y SCP se ejecutan con `-S ssh05`, usando el cliente ssh05 como
  transporte SSH.
- Esto permite transferir con:
  - claves y agente SSH;
  - `ssh_config` habitual;
  - contraseñas `#!! encPassword`;
  - ProxyJump y opciones de ssh05.
- `ssh05` acepta `-q`, que sftp/scp pasan al invocarlo.
- Nuevo flag `ssh05d --ssh05 <ruta>` para elegir el binario de transporte.
- Si la transferencia falla, el panel permite **Reintentar** con `r` o con el
  botón, sin reiniciar la app.

## Errores

- `Esc` cierra primero el aviso de error, aunque haya un panel abierto.
- El aviso se puede cerrar con clic.
- El foco vuelve a hosts al cerrar el aviso o los paneles.
