# ssh05 0.40.0

Fecha: 25/11/2026

Esta versión cierra el fallo de conexión con host keys nuevas desde la UI y
completa la navegación con ratón.

## Host keys sin `/dev/tty`

- `ssh05d` ya no intenta pedir confirmación por terminal.
- Una clave desconocida devuelve `host_key_unknown` con tipo y huella SHA-256.
- La UI muestra un diálogo para aceptar o cancelar.
- `hosts.trustKey` vuelve a sondear el servidor, comprueba que la huella coincide
  y solo entonces escribe `known_hosts`.
- Una clave cambiada devuelve `host_key_changed` y nunca se sobrescribe.
- El supervisor no lee contraseñas, passphrases ni PIN de `/dev/tty`, aunque se
  arranque desde una terminal.

## Ventana SSH

- Cada sesión se muestra en un marco con cabecera de estado, host, ruta y tmux.
- La `×` cierra la conexión (`close-view`).
- El clic derecho en `×` abre las opciones de cierre: vista, SSH o tmux.
- El título se trunca para que la `×` permanezca visible.

## Ratón y menús

- Hosts: clic selecciona, doble clic conecta, clic derecho abre acciones y la
  rueda desplaza.
- Pestañas: clic activa, clic derecho/central abre el cierre, rueda cambia.
- Barra superior: hover resalta y clic ejecuta.
- Menús: filas clicables, hover, iconos, descripciones, botones `[ Acción ]` y
  scroll en listas largas.
- Formularios: clic directo en campos y acciones.
- Navegación de teclado ampliada con `Home`, `End`, `PageUp` y `PageDown`.
