## Cambios

- **Un solo comando de entrada.** `ssh05` sin argumentos abre la interfaz
  OpenTUI (`ssh05-ui`) cuando está instalada.
- `ssh05 usuario@host` y el resto de argumentos siguen usando el cliente
  clásico compatible con OpenSSH.
- `SSH05_NO_UI=1 ssh05` fuerza el gestor de hosts clásico.
- `ssh05-ui` se mantiene como alias/compatibilidad.
- En instalaciones sin `ssh05-ui` (por ejemplo, solo `go build`), `ssh05`
  conserva el gestor clásico.

## Verificación ejecutada

- `bin/ssh05` sin argumentos en tmux abre la UI OpenTUI.
- `SSH05_NO_UI=1 bin/ssh05` abre el gestor clásico.
- Prueba `TestLaunchOpenTUIMissingFallsBack`.
- Tests Go completos y `ui-smoke` (91 comprobaciones).

## Límites conocidos

1. Si `ssh05-ui` existe pero Bun falla, el proceso termina con el error de la
   UI; no se reintenta el gestor clásico automáticamente.
2. En Windows el frontend OpenTUI no está empaquetado.
